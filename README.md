## GitHub Pages

1. Create a new GitHub repository, e.g. `downtown-vines`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. If using a custom domain, add it under Settings → Pages → Custom domain.
5. Keep the included `CNAME` file only after replacing its value with your real domain.
